# Contributing

Contributions are welcome. Please keep the project dependency-light and focused on deterministic local HTTP mocking.

1. Fork and create a focused branch.
2. Install with `python -m pip install -e .`.
3. Run `python -m unittest discover -s tests -v`.
4. Add tests for behavior changes and update both README language sections when user-facing behavior changes.
5. Open a pull request describing the motivation and validation performed.

Do not commit credentials, personal data, generated environments, or third-party fixtures without appropriate licensing.
